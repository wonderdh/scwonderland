## 🔴 데이터 불일치 · stale · 누수

**1. `/bus-monitor` TV 가 자정을 넘기면 갱신이 멈춤 (stale)**
`src/app/(monitor)/bus-monitor/BusMonitorClient.tsx:108-110, 150-157, 183-194`
- `dayOfWeek` 는 서버가 넘긴 `initialIsoDay` 로 고정된 state. `isViewingToday = dayOfWeek === getTodayIsoDayKst()` 가 자정 이후 `false` 로 바뀌면 realtime(`enabled: isViewingToday`) 과 15초 폴링(`!isViewingToday` 면 return) 이 **둘 다 꺼짐**. 자정 보정 effect 는 `[]` deps 로 마운트 1회만.
- 결과: 일~월 자정 등 요일이 바뀌면 전날 탭·전날 데이터로 동결. 매일 아침 새로고침하는 운영이면 영향 없음 (추정).
- 이전 지적(REVIEW_REUSABILITY 8.9) 은 "eslint-disable 코드 스멜" 만 언급, 기능적 stale 은 미기재.
- 개선안: 15초 폴링 effect 안에서 `getTodayIsoDayKst()` 를 다시 읽어 바뀌면 `setDayOfWeek` + `loadData`. 폴링 조건에서 `isViewingToday` 의존 제거.

**2. bus 액션 revalidate 전무** — 이전 지적(04-프론트엔드리뷰 #1, 2026-06-14 리뷰). **미해결**. `src/app/(admin)/admin/bus/page.tsx:48-54` 가 RSC 로 `busStops`/`busTimeSlots`/`allStudentNames` 를 prop 주입하므로 정류장·시간대 추가 후 탭 이동 시 stale. 개선안: `closed-days-actions.ts` 의 `revalidateAll()` 패턴으로 `revalidatePath("/admin/bus")` 한 줄씩.

**3. `createClass` 마지막 단계 에러 무시** — 이전 지적(2026-06-14 "createClass 3단계 insert") 에 추가.
`src/app/(admin)/admin/actions/class-actions.ts:450` `await supabase.from("class_schedules").insert(rows);` 결과를 안 받음 → 반은 생기고 시간표 슬롯이 없는 상태가 성공으로 반환. 개선안: `{ error }` 받아 반환 (RPC 전환 전 최소 조치).
