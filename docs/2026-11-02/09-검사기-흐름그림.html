그림 2. 3번 "검색대" 안을 열어 보면

장비가 위에서 아래로 한 줄로 서 있습니다. 보라색이 새로 끼워 넣을 장비, 오른쪽 세 상자가 "3줄" 입니다.

글로 정리

  • 실제로 검사하는 건 장비 본체 파일 하나. 서버 기능 파일을 다 열어서 "신분증 확인(verify) 호출이 있나, 없으면 @auth-skip 메모라도 있나" 를 보고, 둘 다 없으면 파일명과 줄 번호를 찍고 삐.
  • 이름표는 그 파일을 짧은 별명으로 부르게 하는 한 줄. 내 컴퓨터에서도 같은 별명으로 돌려볼 수 있음.
  • 검색대 줄에 끼우는 건 ci.yml 에 "이 별명 실행" 한 단계. 없으면 장비는 있는데 아무도 안 쓰는 상태.
  • 예외 명단은 신분증을 다른 방식으로 확인하는 파일 하나를 "삐 울리지 마" 로 적어 두는 것.
  • 2번(push) 이후는 전부 자동. 사람이 할 일은 빨간 X 뜨면 고치는 것뿐.
