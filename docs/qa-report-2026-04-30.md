## 발견된 버그 및 수정 내역

### 🔴 Critical (기능 완전 불가)

#### 1. `user-actions.ts` — 학생/교사 목록 조회 불가
- **원인**: `students/teachers.profile_id`, `profiles.first_name/last_name`, `user_roles` 테이블 참조
- **증상**: Admin 학생 관리, 교사 관리 페이지에서 목록 미표시
- **수정**:
  - `students.select("profile_id, ...")` → `students.select("id, ...")`
  - `profiles.select("id, first_name, last_name")` → `profiles.select("id, username")`
  - `user_roles.insert(...)` 제거, `profiles.insert({ role })` 추가
  - `students/teachers.update().eq("profile_id", id)` → `.eq("id", id)`

#### 2. `academy/teacher/layout.tsx` — 교사 포털 접근 불가
- **원인**: `profiles.select("first_name")` (없는 컬럼) → 쿼리 실패 → `/academy/login` 리다이렉트
- **원인 2**: `teachers.eq("profile_id", user.id)` → 없는 컬럼
- **증상**: t1 로그인 후 교사 포털이 계속 로그인 페이지로 리다이렉트
- **수정**:
  - `profiles.select("first_name")` 제거, `teachers.select("teacher_type, name")` 사용
  - `.eq("profile_id", user.id)` → `.eq("id", user.id)`
  - `teacherName = profile?.first_name` → `teacherName = teacher?.name`

### 🟠 High (기능 부분 불가)

#### 3. `change-actions.ts` — 버스 변경요청 이름 미표시
- **원인**: `students.select("profile_id, ...")`, `studentMap.get(d.student_profile_id)` 등 구 컬럼 참조
- **증상**: 대시보드 및 승하차 변경사항에 "이름 없음" 표시
- **수정**:
  - `d.student_profile_id` → `d.student_id` (전체 교체)
  - `students.select("id, ...")` 및 `.in("id", ...)` 사용
  - `student_bus_defaults`: `student_profile_id` → `student_id`
  - `students.student_number` 컬럼 없음 → 제거
  - 반환 객체에 `student_profile_id: d.student_id` 추가 (하위 호환)

#### 4. `bus/assignment-actions.ts` — 배정 관리 학생 목록 조회 실패
- **원인**: `listAllActiveStudentNames`에서 `students.select("id, profile_id, ...")` (없는 컬럼)
- **수정**: `profile_id` SELECT 제거, 반환 시 `profile_id: s.id` 사용

### 🟡 Medium (UI 표시 오류)

#### 5. `lib/bus/state.ts` + `lib/constants/bus.ts` — `temporary_change` 타입 미지원
- **원인**: DB에 `change_type = 'temporary_change'` 레코드 존재하지만 `BUS_CHANGE_TYPE_CONFIG`에 없음
- **증상**: 승하차 변경요청 탭에서 `StatusBadge` 렌더링 에러 → 페이지 전체 에러 바운더리 표시
- **수정**:
  - `BUS_CHANGE_TYPES`에 `"temporary_change"` 추가
  - `BUS_CHANGE_TYPE_CONFIG`에 `temporary_change: { label: "임시변경", ... }` 추가
