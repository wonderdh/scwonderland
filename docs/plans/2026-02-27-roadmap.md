# SC Wonderland 전체 구현 로드맵

> 작성일: 2026-02-27
> Notion TODO 기반 전체 구현 계획

## Context

Notion TODO 기반으로 남은 기능 25개를 **병렬 subagent(worktree isolation)** 활용하여 효율적으로 구현하는 전체 로드맵.
현재 기본 기능(Admin CRUD, 학생/교사 포털, 공지사항, 교재)은 완성 상태.

**사용자 결정사항:**
- 전체 로드맵 작성 (모든 TODO 포함)
- (site) 플레이스홀더 7개 → 콘텐츠 미준비, 우선순위 최하
- Admin 학생 탭: 학습 이력 조회/수정, 출결 체크/기록
- 숙제 시스템: 음성 녹음(AudioRecorder) 필수
- 기간 제약 없음

## Step 2: Admin 학습관리 탭 + 출결 탭

### DB 마이그레이션 (Supabase MCP로 적용)

**learning_records 테이블:**
```sql
CREATE TABLE public.learning_records (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  student_profile_id UUID NOT NULL REFERENCES public.profiles(id) ON DELETE CASCADE,
  record_date DATE NOT NULL DEFAULT CURRENT_DATE,
  category TEXT NOT NULL CHECK (category IN ('test', 'assessment', 'note', 'level_change')),
  title TEXT NOT NULL,
  content TEXT,
  score NUMERIC,
  max_score NUMERIC,
  author_id UUID REFERENCES public.profiles(id) ON DELETE SET NULL,
  created_at TIMESTAMPTZ DEFAULT now(),
  updated_at TIMESTAMPTZ DEFAULT now()
);
CREATE INDEX idx_learning_records_student ON public.learning_records (student_profile_id, record_date DESC);

ALTER TABLE public.learning_records ENABLE ROW LEVEL SECURITY;
CREATE POLICY "learning_records_admin_all" ON public.learning_records
  FOR ALL TO authenticated
  USING (EXISTS (SELECT 1 FROM profiles WHERE profiles.id = auth.uid() AND profiles.role = 'admin'))
  WITH CHECK (EXISTS (SELECT 1 FROM profiles WHERE profiles.id = auth.uid() AND profiles.role = 'admin'));
```

**attendance 테이블:**
```sql
CREATE TABLE public.attendance (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  student_profile_id UUID NOT NULL REFERENCES public.profiles(id) ON DELETE CASCADE,
  class_id UUID NOT NULL REFERENCES public.classes(id) ON DELETE CASCADE,
  attendance_date DATE NOT NULL DEFAULT CURRENT_DATE,
  status TEXT NOT NULL DEFAULT 'present' CHECK (status IN ('present', 'absent', 'late', 'excused')),
  note TEXT,
  recorded_by UUID REFERENCES public.profiles(id) ON DELETE SET NULL,
  created_at TIMESTAMPTZ DEFAULT now(),
  updated_at TIMESTAMPTZ DEFAULT now(),
  UNIQUE (student_profile_id, class_id, attendance_date)
);
CREATE INDEX idx_attendance_student ON public.attendance (student_profile_id, attendance_date DESC);
CREATE INDEX idx_attendance_class_date ON public.attendance (class_id, attendance_date DESC);

ALTER TABLE public.attendance ENABLE ROW LEVEL SECURITY;
CREATE POLICY "attendance_admin_all" ON public.attendance
  FOR ALL TO authenticated
  USING (EXISTS (SELECT 1 FROM profiles WHERE profiles.id = auth.uid() AND profiles.role = 'admin'))
```

## 검증 계획

**각 Step 완료 후:** `npm run build` + `npm run lint` + 수동 테스트

**전체 E2E 체크리스트:**
1. Admin 학생 관리 5개 탭 전체 동작 (정보/학습/리포트/교재/출결)
2. 교사 교재 일괄 진도 업데이트 + 학생 제외
3. 한국인 교사: 담당반/공지/반관리/교재/숙제 (5탭)
4. 원어민 교사: My Classes/Reports/Textbooks/Homework (4탭, 영어)
5. 학생: 정보/리포트/교재/숙제/공지 (5탭)
6. 숙제 플로우: 교사 출제 → 학생 AudioRecorder 녹음 제출 → 교사 리뷰
7. 반별 공지: 교사 작성 → 학생 조회 + 첨부파일
8. Academy 공지: Admin 작성 → 학생/교사 조회
9. Storage 파일 업로드/삭제/조회 정상
10. 역할별 접근 제어 (admin/teacher/student)
