## Medium Findings

### Q-M1. 비 admin 사용자가 /admin 접근 시 login 페이지로 rebound (혼재 상태)

**File:** `src/app/(admin)/admin/layout.tsx` (추정)
**재현:**
1. teacher(`lauren`) 또는 student(`rlawndks`) 로 로그인
2. `/admin` 로 직접 네비
3. `/academy/login?error=admin_only` 로 redirect
4. 페이지 헤더는 여전히 `Lauren | Logout` 로 인증 상태 표시
5. main 영역은 로그인 폼

**Issue:** 이미 인증된 사용자인데 로그인 폼이 노출됨. 세션 자체는 유지되므로 "/academy/dashboard" 링크 클릭하면 원래 대시보드로 돌아감 → **mixed state**. 사용자 혼란.

**Preferred UX:**
- 인증 상태 유지 + 본인 대시보드(`/academy/teacher` or `/academy/student`)로 redirect + 토스트 에러 표시
- 또는 완전 로그아웃 후 로그인 폼

**Impact:** UX 일관성. 혼란스런 상태 표시.

**Fix 위치:** admin layout의 role 체크 분기 — role이 "admin"이 아니면 본인 역할의 대시보드로 redirect.

### Q-M2. /admin/textbooks 커버 이미지 성능 경고

**File:** `src/app/(admin)/admin/textbooks/**` 컴포넌트
**URL:** `/admin/textbooks`
**Console:**
```
[warn] Image with src "...textbook-covers/1772009175909_vic9ck.webp"
       has either width or height modified, but not the other.
[warn] Image ... was detected as the Largest Contentful Paint (LCP).
       Please add the `loading="eager"` property if this image is above the fold.
```

**Issue:**
1. `width` 또는 `height` 중 하나만 CSS로 바뀌어 aspect ratio 깨짐
2. LCP 이미지에 `loading="eager"` 없음 → 첫 로드 체감 속도 저하

**Fix:**
- `<Image>` 에 `style={{ width: "auto", height: "auto" }}` 또는 비율 고정
- 첫 번째 card의 cover에 `priority` prop 추가 (또는 `loading="eager"`)

### Q-M3. 학생 대시보드 출석률 계산 의심

**File:** `src/app/(academy)/academy/student/page.tsx` 또는 관련 서버 액션
**URL:** `/academy/student` (로그인: rlawndks)
**증상:**
```
월 출석률 33%
출석 0 · 지각 0 · 결석 2
```
단순 비율로는 0%여야 하는데 33%. 계산 공식이 "기대 출석일 대비 실제 출석" 이거나 다른 가중치 방식일 수 있음. 맞는 로직이라도 **"출석 0 · 결석 2"와 나란히 33%를 보여주는 건 오해 소지 큼** → 툴팁이나 분모 설명 필요.

**Fix:**
- 계산 공식 확인 (`getAttendanceStats` in attendance-actions.ts)
- 공식을 UI 툴팁/설명으로 노출
- 또는 분모 명시: "출석률 N/M (33%)"
