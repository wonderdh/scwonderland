6. 코드 긁으면서 발견한 것

  • 끊긴 탭 2개: 교사·학생 상단 탭에 /academy/teacher/notices, /academy/student/notices가 있는데 해당 폴더가 없어 404. 공지 페이지를 만들거나 탭을 빼야 함.
  • 사이드바에 없는 페이지: /admin/lunch, /admin/lunch/settings는 라우트는 있지만 어떤 메뉴에서도 못 감. 직접 URL로만 접근. /lunch-monitor도 링크 없음.
  • 리딩 상세 링크 없음: /admin/reading/[studentId], /academy/teacher/reading/[studentId]로 가는 <Link>가 코드에 없음. 모바일 /m/reading만 학생별 링크가 있음.
  • 비활성 구역: /bus는 layout이 무조건 /dashboard로 보냄(버스 기사 역할 제거됨). /academy/login은 /login으로 넘기는 호환용.
  • 공개 페이지: /bus-monitor, /lunch-monitor는 인증 없음. URL을 아는 사람은 누구나 볼 수 있음. 의도라면 그대로, 아니면 토큰 쿼리 같은 가드 필요.
